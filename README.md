# Rahul — Cybersecurity Portfolio

A responsive, single-page cybersecurity portfolio ready for GitHub Pages.

## Publish to https://rahul-246.github.io/
1. Open the GitHub repository named `rahul-246.github.io` (create it if it does not exist).
2. Upload `index.html` and the `assets/` folder to the repository root, preserving paths.
3. Under Settings → Pages, select **Deploy from a branch**, `main`, and `/ (root)` if not already enabled.
4. Open https://rahul-246.github.io/ after deployment completes.

## Before publishing
- Add your real LinkedIn profile URL (replace `https://www.linkedin.com/`).
- Add your email/contact links and optional resume PDF download.
- Confirm MANIT joining date and TECHPLEMENT exact dates/job title.
- Confirm B.Tech college and graduation year.
- Verify all wording against your resume and work history.
- The terminal display is explicitly illustrative, not a live SIEM feed.

No build tools or hosting service required. Fonts load from Google Fonts, with system fallbacks.
